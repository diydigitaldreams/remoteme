# MVP Roadmap

## Phase 1: App Foundation

- Define schemas for user profile, job post, score result, draft package, and application records.
- Define prompts for scoring, tailoring, cover letters, and follow-ups.
- Document import flow for resume, LinkedIn, Indeed, and job posts.

## Phase 2: Local Prototype

- Build a simple web interface.
- Allow user to paste career material.
- Allow user to paste a job post.
- Normalize inputs into structured JSON.
- Generate a fit score and recommendation.
- Generate draft application materials.

## Phase 3: Tracker

- Add application tracker table.
- Allow users to save scored jobs.
- Add statuses and follow-up dates.
- Add filtering by recommendation, status, and remote/location risk.

## Phase 4: Import Improvements

- Add resume file upload.
- Add LinkedIn text import helper.
- Add Indeed text import helper.
- Add job URL import if legally and technically appropriate.

## Phase 5: Polish

- Add review screens before draft export.
- Add export to markdown/PDF/DOCX.
- Add privacy controls.
- Add clear warnings for unverifiable claims.

## MVP Definition of Done

RemoteMe is useful when a user can:

1. Paste career material.
2. Paste a remote job post.
3. Get a fit score.
4. See risks and remote/location restrictions.
5. Generate a cover letter draft.
6. Save the role to an application tracker.
